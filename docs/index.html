Capacidades del Sistema

Arquitectura Diseñada para Operadores y Radioingenieros

Herramientas avanzadas integradas para modelar, diagnosticar, calcular y supervisar la red móvil celular.

🧬

Algoritmo Genético Multi-Ejecución

Evolución simultánea mediante operadores genéticos adaptativos: selección por torneo, mutación guiada únicamente en las celdas marcadas para recálculo, cruce por bloques de estación y elitismo para conservar el mejor plan global.

📻

Reconfiguración de Espectro (Autofreq)

Transición fluida ante reasignaciones de espectro regulatorio. Detecta canales en uso (tanto BCCH como todos los TCH), sustituye heurísticamente frecuencias que desaparecen y aprovecha nuevos canales disponibles para desatascar la red.

📐

Modelos Estadísticos de Traspaso

Flexibilidad para ponderar la severidad de las interferencias según el tráfico real. Selecciona entre formulaciones Logarítmica, Lineal Normalizada, Sigmoide, Exponencial/Pareto y Clásica según el perfil de la red (urbana, hotspot o rural).

📊

Análisis Agregado por Canal (ARFCN)

Gráfica de barras interactiva en HTML5 Canvas para supervisar la carga espectral. Visualiza coincidencias totales, portadoras BCCH, tráfico TCH o conflictos por frecuencia, con inspector de celdas en tiempo real.

🌐

Dashboard HTML Interactivo (3 Escenarios)

Sustitución completa del informe PDF estático por un dashboard dinámico, moderno y ligero con selector de tema, alternancia en vivo entre escenarios, matriz comparativa con % de mejora y filtros de celdas modificadas.

🗺️

Visualización GIS y Mapa Sectorial

Mapa de frecuencias interactivo con representación geométrica de estaciones base y acimuts de sector, identificando visualmente grupos de reutilización y riesgos de interferencia cocanal.

Fundamentación Matemática

Modelos Estadísticos para Ponderación de Pesos

Comprende y simula en tiempo real cómo impacta cada modelo en la penalización de interferencias entre celdas vecinas.

Modelo Logarítmico

w(HO) = log₂(1 + HO)

Comprime la varianza extrema del tráfico de handovers mediante compresión sublineal logarítmica. Evita que un par de celdas muy transitadas monopolice el cálculo de la función de coste.

Criterio de Uso Óptimo Ideal para redes GSM urbanas estándar con tráfico heterogéneo y topología celular densa.

Instalación y Ejecución en 3 Pasos

Desarrollado en Python 3 puro con PyQt6. Totalmente compatible con Windows, macOS y Linux.

bash — Clonar y Ejecutar 
# 1. Clonar el repositorio
git clone https://github.com/angel190385/2G-Frequency-planner.git
cd 2G-Frequency-planner

# 2. Instalar dependencias requeridas
pip install -r requirements.txt

# 3. Lanzar la aplicación gráfica de escritorio
python main.py

# (Opcional) Ejecutar suite completa de tests automatizados
python -m unittest discover tests
